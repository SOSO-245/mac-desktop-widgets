# 注意要点
- 仅支持 Apple Silicon / macOS 14+；Intel 不运行采集器。
- 无管理员权限，无上传遥测；不读取个人文件、账号、进程命令行或 VPN 配置，不切换网络。
- macmon 的私有硬件接口可能随 macOS 改变；不可用显示 —，采集失败有限频率重启，关闭应用终止子进程。
- 系统小组件使用 127.0.0.1:18766 的只读快照，含 CPU、内存等数字，无凭据。不要绑定外网。
- 主应用与扩展版本号必须一致；扩展签名保留 sandbox 和 network.client。实际显示需本机验证。
- Vendor/macmon-source-final 是只读上游参考，不发布其 .git、开发日志或个人状态；分发保留 MIT 许可证。
