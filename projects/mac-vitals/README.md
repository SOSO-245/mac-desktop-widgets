# Mac 实时监测

当前源码 1.2.0，macOS 14+ / Apple Silicon。显示系统功率估算、CPU、内存、温度与物理网卡流量；实时卡片每秒更新，WidgetKit 小组件的实际刷新由系统调度。

菜单栏“设置…”或 ⌘, 打开统一设置，集中调整登录启动、桌面显示/尺寸/锁定/置顶、菜单栏文字与颜色、浮窗和软件更新。应用与其他五款保持独立，沿用原偏好。

采集器为 MIT 开源 macmon v0.10.0。系统功率是 SMC 估算，不是插座实测，不包含外接显示器；不可用时按现有规则显示芯片功率。只读组件数据桥绑定本机 127.0.0.1:18766，不上传遥测，不读取 VPN 配置。

构建运行 `python3 build.py`；默认不安装。模型、菜单栏和组件自检测试已纳入仓库根的 `python3 scripts/test_all.py`。发布包使用临时签名，尚未获得 Apple 公证，安装包版本以 Releases 为准。

## 1.2.3 轻量动态监测

实时卡片功率历史曲线增加柔和辉光与最新采样亮点；网速数字左侧用蓝色向下、紫色向上的轻量方向动画，不增加横向轨道。使用真实采集器数据，保留每秒采样。零网速或过期数据停止流动。动画最多 24 帧/秒，减少动态效果时保持静态；系统 WidgetKit 原展示保持不变。

温度前采用原创细线条小脸，与深蓝玻璃、青绿蓝紫配色协调：低于 60°C 青色微笑，60–74°C 绿色平静，75–89°C 黄色，90–94°C 红色微热加汗滴，95°C 起紫色热脸；无有效读数为灰色。分段只用于视觉表达，不代表硬件热保护阈值。Noto Emoji 与 Stats 作为调研参考，最终未复制第三方图片或代码。

## 1.2.5 温度分段与风扇

表情采用 60 / 75 / 90 / 95°C 五档青绿黄红紫，仅为视觉分段，不称为 Apple 官方热保护阈值。每秒读取 ProcessInfo.thermalState：fair/serious 至少黄色，红色仍须达到 90°C，critical 紫色；serious/critical 立即反映。单纯温度上升持续 3 秒才换档，降温低于分界线 3°C 并持续 10 秒才回落，缺失读数保持未知。

直接解析现有 macmon 的 fans 字段，保留每个风扇实际 RPM；零值表示停转，缺失显示 —。大号增加风扇行，小/中号与系统组件底部显示，菜单栏设置可选风扇转速。只读传感器，不设置转速或更改风扇控制。参考 Apple ProcessInfo.ThermalState 和 macmon 公开数据结构；未加入其他采集器。

## 小鸭子皮肤 · 1.3.1（2026-10-28，本地待发布）

设置 → 桌面卡片 → 卡片皮肤，可在监测面板与小鸭子之间切换。小鸭子按真实系统功率（不可用时沿用原芯片功率回退）在 0–50 W 之间移动；超过 50 W 保留真实数值，进度停在终点。读数即时更新，鸭子使用保留速度的临界阻尼平滑游动。缺失或过期功率不显示为 0 W。

小鸭子小号为 164×164，中号 344×164，大号 344×344；原监测面板小号仍为 220×164。工具箱通过可选 smallWidth 字段读取实际布局，兼容旧卡片回执。皮肤和尺寸独立保存。

保留四季造型、镭射雨帽、积雪和清雪、点鸭浮动、点水游泳/先转90°再潜水、手套光标、雨后彩虹、明确雷雨/台风足球和跨卡片闪电落水两次骷髅短闪。天气沿用万年历仅在本机共享的天气类型、原始观测时间及时区；不交换经纬度、联系人或日程。天气缺失/过期时使用四季造型。跨卡片互动沿用原有左侧相邻和真实轨迹规则，不吸引闪电或制造源站感谢。

实时桌面皮肤不改变 WidgetKit 现有布局；系统减少动态效果时尊重原设置。原生小组件、菜单栏与采集器功能保留。小鸭子视觉组件和原创素材复用于本机现有设计，不包含家庭概览项目或生产配置。
