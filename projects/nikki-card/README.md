# Nikki 实时卡片

独立连接 Nikki/Mihomo 控制端，显示实时上下行、当前节点、套餐用量/到期、大号六站点两行三列。支持三尺寸、位置锁定、置顶、可选登录启动。

先到连接设置，把示例 `http://router.local:9090` 改为自己的控制地址，并输入密钥；密钥仅存本机独立钥匙串。接口必须已在旁路由正确配置，程序不会修改路由器监听或防火墙。

右上 ⇄ 进入策略组选择，只对 Selector 组明确点“切换”才写入，并回读确认，不主动关闭现有连接。套餐有多份时在设置中选定，不把不同订阅累加。

站点延迟由旁路由执行：同名组，ChatGPT/Claude 用 AI，bilibili 用 DIRECT，缺失时回退展示组。不能代表账号/地区解锁。菜单栏显示设置可组合九项信息，全部取消仍保留图标入口。

构建 `python3 build.py`；测试 `python3 Tests/run.py`，只向本机模拟接口测试节点写入，不操作真实路由器。

## 注意要点

macOS 14+；当前发布为临时签名，未公证。运行时的私人配置不在仓库中；来源许可见根 THIRD-PARTY-NOTICES.md。默认构建不会安装应用。

菜单栏显示设置支持九项独立开关和七项自定义颜色；全部关闭仍保留入口图标，同一线路常规测速保留旧值直到新结果返回。默认常规延迟荧光绿、超过 2000 ms 粉红色。
