# Nikki 实时卡片

当前源码 1.3.0：每款独立的统一设置窗口。菜单栏“设置…”或卡片省略号进入，连接、套餐、测速、桌面、菜单栏和更新集中管理；策略组与节点选择继续使用原业务窗口。

独立连接 Nikki/Mihomo 控制端，显示实时上下行、当前节点、套餐用量/到期、大号六站点两行三列。支持三尺寸、位置锁定、置顶、可选登录启动。

先到连接设置，把示例 `http://router.local:9090` 改为自己的控制地址，并输入密钥；密钥仅存本机独立钥匙串。接口必须已在旁路由正确配置，程序不会修改路由器监听或防火墙。

右上 ⇄ 进入策略组选择，只对 Selector 组明确点“切换”才写入，并回读确认，不主动关闭现有连接。套餐默认按当前策略组的最终节点自动匹配；兼容仅出现在 provider 列表的节点。同名节点归属多个订阅时不猜测，可以在设置中手选。不同订阅不会累加。

站点延迟由旁路由执行：同名组，ChatGPT/Claude 用 AI，bilibili 用 DIRECT，缺失时回退展示组。不能代表账号/地区解锁。菜单栏显示设置可组合九项信息，全部取消仍保留图标入口。

构建 `python3 build.py`；测试 `python3 Tests/run.py`，只向本机模拟接口测试节点写入，不操作真实路由器。

## 注意要点

macOS 14+；当前发布为临时签名，未公证。运行时的私人配置不在仓库中；来源许可见根 THIRD-PARTY-NOTICES.md。默认构建不会安装应用。

菜单栏显示设置支持九项独立开关和七项自定义颜色；全部关闭仍保留入口图标，同一线路常规测速保留旧值直到新结果返回。默认常规延迟荧光绿、超过 2000 ms 粉红色。

## 桌面小组件与显示开关

桌面右键 → 编辑小组件 → 搜索“Nikki 实时卡片”，支持小、中、大号；大号展示六站点。显示套餐、节点、当前连接数和流量；点击主体打开实时卡片，点击节点栏打开节点选择窗口。应用需保持运行，小组件每分钟申请刷新，实际由 macOS 调度；旧快照会隐藏过期网速与延迟。

“设置 → 桌面与浮窗 → 显示桌面卡片”可隐藏或恢复卡片；重启记住状态，菜单栏和组件供数继续。

更新后若 macOS 提示读取原有钥匙串项目，请在本机按系统提示确认。确认前数据读取可能等待；不要在 GitHub Issue 或聊天中提供系统密码、控制密钥。测试机授权后已验证供数恢复。应用自检只修复自己的旧临时组件注册，不清空系统缓存，也不会修改 VPN 或节点。


## 网速统计范围

点上传或下载速度切换“仅代理 / 代理＋直连”，或在“设置 → 数据与连接 → 网速统计”中选择。三个卡片尺寸均支持且记住设置；单绿点为仅代理，绿＋紫双点为代理＋直连。切换重建曲线，菜单栏速度同步。

含直连使用核心 `/traffic`，不包含绕过核心的流量。仅代理按每秒 `/connections` 活动连接快照差分，以实际出站节点过滤 DIRECT、命名直连和拒绝节点，短连接可能漏计；不是套餐计费用量。切换、过期、计数回退和重连不会沿用旧速率。

系统小组件随快照显示范围，旧缓存兼容；中/大号速度区可打开应用切换并申请刷新。系统调度可能延后，实际桌面新标记绘制仍待验收。

 套餐定时刷新
设置 → 数据与连接新增套餐定时刷新：默认每小时，可关闭或选择 30 分钟、3/6/12 小时；支持立即刷新。应用运行且已连接时执行，隐藏卡片不停止；不增加系统定时任务。仅刷新当前自动匹配或手选的 HTTP 订阅，同步用量、有效期与订阅节点列表，不主动切换节点。使用上游更新时间及本机持久化请求时间防止重启或失败形成请求循环；失败保留已有读数，下个周期重试。
