# VPN 实时卡片

当前源码 1.4.0：统一设置、节点选择与测速。应用仍独立运行，当前安装包版本以仓库 Releases 为准。

可拖动 AppKit 桌面面板，监测本机 FlClash 或 Shadowrocket。三种尺寸、位置锁定、套餐用量与到期、实时流量曲线，大号六站点两行三列；菜单栏延迟与剩余额度圆环。

不是 VPN 客户端，不附带节点/订阅。FlClash 兼容 0.9.1 的本机配置与 SQLite profiles，使用其已经启用的 loopback 控制接口和认证。Shadowrocket 只读共享数据，系统可能要求单独授权，数据格式兼容性随版本变化。

流量来自所选客户端，不用整机流量代替。站点测速只走对应本机代理或已验证 VPN 隧道，无法确定路径则不测试。切换显示来源仅打开客户端，不启停 VPN 或自动切换节点。

从菜单栏或卡片省略号的“设置…”进入同一窗口。通用、桌面与浮窗、菜单栏、数据与测速、软件更新集中管理；显示选项立即保存，登录启动在通用页设置。

构建 `python3 build.py`。模型测试 `bash Tests/run-tests.sh`、`bash Tests/run-shadowrocket-tests.sh`、`bash Tests/run-site-tests.sh`；节点相关测试 `bash Tests/run-node-tests.sh`、`bash Tests/run-shadowrocket-node-tests.sh`、`bash Tests/run-node-picker-tests.sh`，均已纳入根 `scripts/test_all.py`。

## 节点选择与测速

中/大号右上 ⇄ 左键切换 FlClash / Shadowrocket 显示来源并打开客户端，右键打开节点窗口；小号从省略号进入“节点选择与测速…”。菜单栏也提供该入口。打开列表自动测速，可搜索节点和手动排序；测速本身不切换节点，只有点击可选节点才发送选择请求。

FlClash 使用已启用的本机控制接口，对可手动选择的组提交节点，并回读确认。Shadowrocket 只列当前订阅内的节点，通过客户端选择 URL 切换；全局重名（忽略大小写）、重复身份、订阅归属不明确或读取期间变化时拒绝选择。套餐剩余、到期与重置提示不会当成真实节点。

Shadowrocket 节点测速是经物理接口发起的 TCP 握手，不代表代理连通或出口耗时；Hysteria2、TUIC、WireGuard 等类型不提供该项结果。客户端选择 URL 只带节点名称，不携带订阅、地址或密码。关闭窗口或切换卡片来源会取消未完成的请求，应用不启停 VPN。

## 注意要点

macOS 14+；当前发布为临时签名，未公证。运行时的私人配置不在仓库中；来源许可见根 THIRD-PARTY-NOTICES.md。默认构建不会安装应用。

菜单栏显示设置支持九项独立开关和七项自定义颜色；全部关闭仍保留入口图标，同一线路常规测速保留旧值直到新结果返回。默认常规延迟荧光绿、超过 2000 ms 粉红色。


## 网速统计范围

点上传或下载速度切换“仅代理 / 代理＋直连”，或在“设置 → 数据与测速 → 网速统计”中选择。三个卡片尺寸均支持且记住设置；单绿点为仅代理，绿＋紫双点为代理＋直连。切换重建曲线，菜单栏速度同步。

含直连使用核心 `/traffic`，不包含绕过核心的流量。仅代理按每秒 `/connections` 活动连接快照差分，以实际出站节点过滤 DIRECT、命名直连和拒绝节点，短连接可能漏计；不是套餐计费用量。切换、过期、计数回退和重连不会沿用旧速率。

Shadowrocket 现有接口无法可靠拆分代理/直连，仍用灰点标记隧道总流量。
