# 家庭概览

macOS 14+ 的 Home Assistant 家庭状态面板、菜单栏、桌面卡片及三尺寸系统小组件。只读访问用户自行配置的 HA。

公开版本不含服务器凭据、设备实体映射或用户缓存；首次打开需填写自己的 HA 地址、令牌及实体。令牌保存在本机钥匙串，实体映射保存在本机配置。

2.4.3：原生皮肤与动画皮肤；动画角色可选黄鸭或白天鹅，支持季节、天气、生日装扮与点击水面互动。角色移动采用平滑响应，大中小号均保留刷新与锁定。功率为各电表实际返回值，缺失时明确标注；应用每秒请求，设备自身上报频率可能较低。

运行 `python3 build.py` 构建，需完整 Xcode。运行 `python3 Tests/run.py` 验证；测试仅使用示例数据。不自动配置或修改 HA。

源码、测试、资源分别位于 Sources、Tests、Resources。原创素材可随本项目 MIT 许可使用；第三方依赖见根目录声明。
