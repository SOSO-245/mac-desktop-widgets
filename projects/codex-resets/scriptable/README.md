# Codex 重置 · iPhone 小组件

这是 Scriptable 脚本，不是需要自行签名的 IPA。手机独立读取公共数据，Mac 无需开机。支持 iPhone/iPad 主屏幕小、中、大尺寸；本版未设计锁屏组件或 Android 组件。

## 安装

1. 在 iPhone 的 App Store 安装 [Scriptable](https://scriptable.app/)。把 `Codex重置.js` 或随包的 `Codex重置-复制用.txt` 通过隔空投送、文件或微信保存到手机。
2. 打开文件，复制全部代码。在 Scriptable 点右上角 `+`，粘贴代码，将脚本命名为「Codex 重置」。点运行，选择小、中、大任一种预览；如系统询问是否访问 codex-resets.com，允许此网站请求。
3. 回主屏幕，长按空白处 → 编辑/添加小组件 → Scriptable → 选择尺寸并添加。长按新组件 → 编辑小组件 → Script 选「Codex 重置」。无需填写 Parameter；脚本设置了点击后打开重置网站。

更新只需用新版代码替换同名脚本，不用重新添加桌面组件。预览出现正常数据后再添加；首次无数据时检查手机是否能打开 https://codex-resets.com/zh-CN ，重新运行脚本即可重试。

## 显示

- 明确计划：粉红色系统倒计时，下面保留计划日期与时间。
- 暂无计划：荧光绿「已重置 X 天 X 小时」，按最新公告时间计算完整天数和小时。
- 计划到点：下次脚本运行显示「等待确认」，不擅自当作已重置。
- 计划没有具体日期：显示「时间待定」。观察窗口不冒充明确计划。
- 中号增加累计次数和平均间隔；大号增加最近三次记录。总次数和平均间隔取源站统计，不用最近三条自行计算。
- 整张组件点开来源网站；深蓝、青绿与紫色渐变，左上角循环箭头图标。
- 失败时保留有效缓存并标记「缓存」，没有缓存显示占位，不展示示例或虚构读数。

## 刷新与范围

数据申请每 5 分钟更新，计划到点或经过整小时会提前申请。实际唤醒由 iOS 决定，不能承诺固定 5 分钟到达；手机低电量等情况可能延后。系统日期计时控件在组件上自行更新时间差，不会每秒访问网络。

Scriptable 的系统计时控件在未来日期经过后可能继续正向计时；脚本只有被 iOS 再次运行后才能切换「等待确认」。因此界面保留绝对计划时间，到点不等于额度已到账。无计划的中文天/小时文字也在下次刷新更新。本版不显示伪实时“当前时钟”。

数据来源为 [Codex Resets 社区公开 API](https://codex-resets.com/api/docs)，这是公告追踪，不是你的个人账户余额或配额。无需 OpenAI 账号、密钥、通讯录或 VPN 数据权限。

## 验证状态

已在 Mac 验证当前公开状态/历史接口 HTTP 200；53 项离线检查通过，覆盖状态解析、计划到期、观察与未知日期、缓存保护、304、429 和三尺寸布局高度预算。布局预算使用近似字体尺寸，并非真实 iOS 排版验收。尚未在用户 iPhone 的 Scriptable 上运行，实际字体、字号缩放和系统刷新频率需要手机确认。

参考：[Scriptable 小组件与刷新](https://docs.scriptable.app/listwidget/)、[系统日期计时控件](https://docs.scriptable.app/widgetdate/)。

## 脚本更新

在 Scriptable 内运行本脚本，尺寸菜单中选择「检查脚本更新」。只连接本项目 GitHub，展示新版说明，经你确认才下载；校验版本、来源及 SHA256 后备份并替换当前脚本。取消、校验失败或替换失败保留/恢复旧脚本；多个同名脚本时停止，避免覆盖错误文件。备份在 Scriptable 的 CodexResetsScriptBackups 文件夹。手机端不在后台静默改代码。当前版本需要先手动安装一次，之后可用此入口更新。
