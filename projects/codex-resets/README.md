# Codex 重置

显示 Codex Resets 社区公告，不读取个人账号额度。三尺寸组件，菜单栏重置倒计时；点击组件直达来源网站，刷新按钮独立工作。

明确未来计划采用粉红倒计时；没有计划显示荧光绿的上次重置经过天数。到点显示待确认，不自行认定发生重置。离线带缓存提示，不按平均间隔预测。

每五分钟申请 WidgetKit 刷新，实际调度由系统控制；秒级倒计时不按秒请求网络。请求固定公开 HTTPS API，保留来源回链。无需令牌。构建 `python3 build.py`，测试 `bash Tests/run-tests.sh`。

## 注意要点

macOS 14+；当前发布为临时签名，未公证。运行时的私人配置不在仓库中；来源许可见根 THIRD-PARTY-NOTICES.md。默认构建不会安装应用。

## 1.0.8 后台运行

运行及打开窗口时不再显示 Dock 图标；从菜单栏或原桌面组件入口打开窗口，关闭窗口后继续供数。登录启动、菜单栏、卡片与组件设置保留。如曾手动固定在 Dock，请右键该图标，在选项中取消“在程序坞中保留”。应用不会替你修改 Dock 固定项目。
