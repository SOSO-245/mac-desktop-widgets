# Codex 重置 · Mac 桌面小组件

独立的 macOS 14+ 原生 SwiftUI / WidgetKit 应用，读取 Codex Resets 公共 API，提供小、中、大三种桌面组件。内容为计划倒计时、最近重置公告、累计次数、平均间隔及最近三条记录。与个人账户剩余额度无关。

## 入口与交付

- `Sources/Model.swift`：公开数据模型、ETag 请求和成功缓存。
- `Sources/ResetCard.swift`：三尺寸界面，原生容器相对边框。
- `Sources/Widget.swift`：WidgetKit 时间线、手动刷新、点击前往网站。
- `Sources/Host.swift`：显式管理/预览窗口、组件网页跳转及原生图片导出。
- `build.py`、`Assets/`：双 target 本机构建与图标。
- `data-source.md`、`Tests/`：来源协议与测试资料。

构建：`python3 build.py`；本机安装：`python3 build.py --install`。
测试：`Tests/run-tests.sh`。原生示例导出：`~/Applications/"Codex 重置.app"/Contents/MacOS/"Codex 重置" --render-previews <目录>`。
交付包括 `交付/Codex重置-Mac.zip`、`交付/Codex重置-完整项目.zip` 和使用与分享说明。
源码单独打包为 `交付/Codex重置-源码.zip`，包含当前 1.0.9 源码、Xcode 工程、资源、测试及构建说明；全量构建需要安装 Xcode。


中号、大号倒计时右侧显示当前本地时间（HH:mm），小号不显示。Widget 预生成 1 小时的整分钟时间线（1.0.3 起，避免桌面时间线归档过大），时钟更新不触发网络；每 5 分钟申请加载新时间线，实际执行由系统决定。刷新停止超过提供的时间线范围时，时间可能停留在最后条目，因此不能作为高精度计时器。

已完成本地安装、公开 API 连通及原生组件检查。最终验证结果见下方记录。

## 注意要点

- 数据来自 https://codex-resets.com/zh-CN，所有尺寸保留来源，主体点击打开原网站。无需登录或令牌。
- 不读取、修改家庭用电、HA、Android TV、Apple TV 项目的数据或配置；不注册后台启动项。
- 计划时间到期仅显示“待确认”，不推断重置成功。没有明确计划时不根据平均间隔预测下次时间。
- 时间内部为绝对时间、显示按 Mac 当前时区；系统控制刷新频率，5 分钟是申请周期，非保证。
- 主 App 和 Widget 共用模型代码，各自在自己的存储域缓存公开数据；不需要 App Group 或本地代理。
- WidgetKit 将点击 URL 交给主应用，不能把 `.widgetURL(https…)` 当成已完成浏览器跳转。网页入口由应用统一转发至固定站点；禁止恢复自动 SwiftUI WindowGroup 或在启动完成时无条件打开管理窗。
- 网络故障保留缓存并标记；首次失败显示占位，示例仅用于明确标注的预览。
- Widget 边框必须使用 ContainerRelativeShape，不硬编码系统组件圆角。
- arm64 + x86_64 通用二进制、本地 ad-hoc 签名，不使用 Apple 账号，未经过 Apple 公证；仅 Apple Silicon 本机实测，Intel 真机及另一台 Mac 未验收。
- 构建在临时目录；安装至用户 Applications 后仅清理新 app 的扩展属性，并严格核验签名，避免桌面同步元数据导致签名问题。
