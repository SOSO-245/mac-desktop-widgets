# 桌面工具箱

六款桌面卡片的统一入口：万年历、家庭概览、重置监测、Nikki、VPN 监测、Mac 实时监测。各软件仍独立运行和保存设置，工具箱只交换卡片尺寸、位置、可见状态等布局信息，不读取连接密钥或业务数据。

## 使用

1. 启动需要的卡片软件和桌面工具箱。
2. 左侧查看按真实尺寸缩放的模拟桌面；右侧勾选卡片，选择小／中／大、排列顺序、目标屏幕和左上／右上起点。
3. 点击「确认并应用排列」才改变真实卡片的尺寸和位置。工具箱检查是否全部放得下，并在执行后核对实际位置；空间不足时不执行。
4. 「恢复上次位置」恢复上一次执行前的尺寸、坐标和显示状态。拖动吸附、尺寸变化自动重排均为可选设置，随确认应用生效。自动重排需工具箱保持运行；预览修改期间不会自动应用待确认的布局。

间距为 16 点；164 点小卡片可两张并排，344 点中／大卡片共享同一列宽。VPN、Nikki、Mac 监测的小号为现有的 220×164，按实际宽度排放，不拉伸。高度不够换列，所有卡片保持在选定屏幕的可用区域内。系统 WidgetKit 小组件不参与排列。

每个应用的设置页新增「桌面排列」入口，工具箱亦可打开各自设置或显示／隐藏单张卡片。显示／隐藏按钮是明确的即时操作；尺寸、选择、顺序仅影响预览。

## 开发与验证

- `Sources/ToolboxShared.swift`：布局尺寸模型和纯布局算法。
- `Sources/Host.swift`：桌面模拟、确认执行、位置回退、统一外观、应用入口。
- 共同的 `ToolboxBridge.swift` 在六款应用内部操作其自己的窗口，通过本机通知交换布局命令。
- `Assets/GenerateIcon.swift`：原创网格图标。
- `python3 build.py`：生成 Apple Silicon、macOS 14+ 安装 ZIP；不自动安装、移动卡片或发布。
- `xcrun swiftc -parse-as-library Sources/ToolboxShared.swift Tests/GridTests.swift -o /tmp/grid-tests && /tmp/grid-tests`：混合尺寸、换列、边界、负坐标显示器与吸附检查。

本地状态位于用户 Application Support/HomeAtlasToolbox，包含布局元数据、上一次位置和可选网格设置。没有维护定时任务或额外系统权限。

## 注意要点

- 首次打开和更改预览不能移动真实卡片；必须由用户确认应用。
- 不修改 VPN、旁路由节点、HA、日历、通讯录或系统小组件位置。
- 旧版卡片没有工具箱接口，应先更新；运行状态过期时禁止应用，不能假装成功。
- 图标和动作保持各应用原有风格；位置锁定不阻止用户明确的一键排列，排列后保留锁定设置。
- 构建在临时目录进行，避免桌面云同步附加属性破坏签名。只有安装包和说明写入交付目录。
- 2026-10-27：用户已在工具箱确认应用，六款回执已核对。统一背景明暗和透明度亦在六款中一致。

统一外观支持原有配色／毛玻璃、明暗和背景透明度。滑块仅影响预览；确认排列时可一并应用，也可点击「仅应用外观，保持位置」。文字不参与透明度变化。外观更改也保留在上一次状态中，可随恢复位置还原。

验证：262 项纯布局检查、隔离桥接测试（尺寸／位置／外观／越界拒绝／接收目标隔离／状态回执）、7 项设置回归通过。六款重建安装包已实际解压验签并通过隐私标记扫描；公开源码检查 360 项无匹配。随 v2026.10.28-r1 提供安装包与源码；工具箱当前手动更新。

卡片右上角已移除省略号菜单，设置统一从菜单栏「设置…」或桌面工具箱进入。刷新、锁定及节点快捷操作保留。

## 1.0.1 接入修复

首次启动仅勾选已响应且可见的卡片，未安装或未启动的可选软件不会阻塞其余卡片。预览选择、尺寸、顺序和外观保存在独立草稿，重开保留；草稿不会自行启用自动排列。等待提示具体列出未启动或尚未响应的软件。勾选自动重排后，仍需确认应用一次。

## 1.0.2 小鸭子尺寸兼容

读取卡片回执的可选小号宽度；Mac 小鸭子小号按 164×164 排列，监测面板小号仍为 220×164。自动重排同时检测实际宽高变化，切换皮肤不再使用旧宽度。旧版应用回执继续兼容。
