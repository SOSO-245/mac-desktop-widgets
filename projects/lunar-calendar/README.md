# 万年历

公历/农历、节气、传统与国际节日、中国法定调休自动更新；支持三尺寸组件、日期快速选择、生日和重复日程。

法定假期数据取自 holiday-cn，每个北京时间自然日自动检查；应用运行时零点触发，启动/唤醒补查，失败保留缓存。官方未公布的年份不推断调休。节日名称与法定休息安排分开。桌面点选 30 秒、其他日期浏览 60 秒不操作返回今日；WidgetKit 实际显示可能延迟。

生日关联联系人和日程同步由用户主动保存时请求系统授权。不会批量读取或上传联系人/日程。日程支持每周、每月、每年；缺少对应日期则跳过。资料只存在本机。菜单栏显示、图标和颜色可选。

构建 `python3 build.py`。完整模型测试见根 scripts/test_all.py；节气固定版本生成源码和许可在 Tools/vendor，普通构建不需要 Node.js。

## 注意要点

macOS 14+；当前发布为临时签名，未公证。运行时的私人配置不在仓库中；来源许可见根 THIRD-PARTY-NOTICES.md。默认构建不会安装应用。

## 1.0.2 后台运行

运行及打开窗口时不再显示 Dock 图标；从菜单栏或原桌面组件入口打开窗口，关闭窗口后继续供数。登录启动、菜单栏、卡片与组件设置保留。如曾手动固定在 Dock，请右键该图标，在选项中取消“在程序坞中保留”。应用不会替你修改 Dock 固定项目。
