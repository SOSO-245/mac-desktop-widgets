# 万年历

当前源码 1.4.0：菜单栏“设置…”或 ⌘, 打开同一个设置窗口，集中调整显示、桌面天气、菜单栏、同步和更新。生日、日程及日历浏览继续使用原业务入口。

公历/农历、节气、传统与国际节日、中国法定调休自动更新；支持三尺寸组件、日期快速选择、生日和重复日程。

法定假期数据取自 holiday-cn，每个北京时间自然日自动检查；应用运行时零点触发，启动/唤醒补查，失败保留缓存。官方未公布的年份不推断调休。节日名称与法定休息安排分开。桌面点选 30 秒、其他日期浏览 60 秒不操作返回今日；WidgetKit 实际显示可能延迟。

生日关联联系人和日程同步由用户主动保存时请求系统授权。不会批量读取或上传联系人/日程。日程支持每周、每月、每年；缺少对应日期则跳过。默认资料只保存在本机；用户选择 iCloud 云盘专用文件夹后，可同步生日、日程和显示设置，本机联系人/系统日历标识不参与同步。菜单栏显示、图标和颜色可选。

构建 `python3 build.py`。完整模型测试见根 scripts/test_all.py；节气固定版本生成源码和许可在 Tools/vendor，普通构建不需要 Node.js。

## 注意要点

macOS 14+；当前发布为临时签名，未公证。运行时的私人配置不在仓库中；来源许可见根 THIRD-PARTY-NOTICES.md。默认构建不会安装应用。

## 1.0.2 后台运行

运行及打开窗口时不再显示 Dock 图标；从菜单栏或原桌面组件入口打开窗口，关闭窗口后继续供数。登录启动、菜单栏、卡片与组件设置保留。如曾手动固定在 Dock，请右键该图标，在选项中取消“在程序坞中保留”。应用不会替你修改 Dock 固定项目。

## 1.4.3 整张天气卡片气氛动画（2026-10-27）

中号日期＋天气桌面卡片增加原生 Canvas 背景动画：雨线、雾带、风线、雪粒、霜纹、台风旋流、沙尘，以及轻柔雷雨云光。在内容后方绘制，不拦截点击；沿用玻璃底色。设置 → 日历与天气可开关、调节 20–100% 浓度，展开“预览特殊天气效果”可独立演示，不改变真实天气。系统减少动态效果时静止。当前实现仅用于应用桌面天气卡片，不用于 WidgetKit 持续动画。

按有效当前天气触发；零下温度的薄霜是装饰而非预警。台风/沙尘只接受来源明确名称，不从高风速或 PM2.5 推断；当前 Open-Meteo 数据源没有对应明确分类时只能预览。新增以 m/s 获取风速并兼容旧缓存，未增加定位权限或账号访问。14 项分类/旧数据检查和八种离线效果图通过；已安装 1.4.3（20261027210204），实际设置开关、滑块及下雨预览验证通过；未等待真实极端天气验证。
