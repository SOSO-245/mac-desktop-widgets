# 浮窗外观与万年历同步

六款应用从菜单栏“设置…”进入统一设置，可选择原有玻璃卡片或原生毛玻璃菜单。默认保留原风格。采用系统毛玻璃材质的自定义面板，保留日期点击与测速交互。

桌面设置页集中提供卡片尺寸、锁定、置顶、显示和背景明暗；支持原配色的应用可切换毛玻璃，万年历采用固定系统毛玻璃。保留“接近桌面小组件”预设，不修改 WidgetKit 的系统外观。

万年历的 iCloud 多台 Mac 同步已移入统一设置的同步页。在各台 Mac 选择同一 iCloud 云盘专用文件夹。同步生日、日程和显示设置；本机的联系人/系统日历关联、开机启动与窗口位置不参与同步。应用运行时每 30 秒检查，云端传输速度由 iCloud 决定。停止同步保留两端数据，首次合并与远端修改前备份本地数据。

同步使用普通 JSON 文件，请勿使用公开共享文件夹。每台 Mac 只写自己的文件，按记录逻辑修订合并，保留删除记录以防旧设备恢复它；同一条记录冲突不做字段级拼接。不能把同步误认为系统日历双向同步：导入的日程不会再次写入系统日历，系统日历后续修改也不会导入。

已通过隔离合并/文件读写检查以及日历回归检查；尚未验证两台真实 Mac 间的 iCloud 传输。安装包不含任何用户生日、日程、密钥或偏好。

Mac 实时监测 1.1.2 的桌面小、中、大尺寸现与 Nikki/VPN 一致：220×164、344×164、344×344 pt，配套紧凑排版。

家庭概览 2.2.0、Codex 重置 1.2.0 起提供独立桌面实时卡片。小号 164×164 与系统小组件一致，现有小号右上显示刷新和锁定；中/大号另有统一设置入口。其余选项在“设置 → 桌面卡片”中调整。

重置卡片接入源站实时感谢数，新增互动飘起淡出爱心。首次/重连不回放旧数据，隐藏时暂停；自己点击爱心才发送一次真实感谢，失败不自动重试。信息区域打开原网站。

### 小号卡片和功率占比更新
家庭概览 2.2.1、重置 1.2.1：小号保持 164×164，显示刷新与锁定状态按钮，桌面主体支持解锁拖动与轻点跳转。重置小号主数字放大到 43 pt。家庭功率独立每 5 秒读取，一位小数；细圆角紫蓝双色进度条显示两个电表功率构成，两户读数在下方分列；今日用电与估算缩小并靠功率右侧。WidgetKit 时间线仍由系统调度。原有配置与隐私隔离不变。

验证：家庭模型/本地 REST 回归、64 项概览断言、23 项重置隔离回归通过，用户已确认重置主体拖动恢复。没有真实测试点赞。

小号高功率排版：主功率低于 1000 W 保留一位小数，达到 1000 W 后显示整数；3000 W 使用离线渲染检查。双色条之间保留 2 pt 间隙，两段分别圆角，比例以扣除间隙后的可用宽度计算，单户为零时不留假分隔。
