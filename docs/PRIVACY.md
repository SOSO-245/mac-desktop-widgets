# 数据与权限

仓库不包含用户缓存、联系人、日程、生日、订阅链接、服务器密钥、家庭设备唯一编号、真实界面截图、系统诊断或旧应用备份。

- 家庭概览：用户自行输入 HA 地址、令牌；令牌在本机钥匙串。只读获取配置实体和历史。
- Nikki：自行输入控制接口和密钥，密钥在独立钥匙串。默认地址是示例 `http://192.168.1.2:9090`，需要改为自己的旁路由。只在用户点击切换时向选定策略组提交修改。
- VPN：按选择读取本机 FlClash / Shadowrocket 必要的配置、节点与订阅字段；不复制到仓库。Shadowrocket 共享数据访问由 macOS 权限控制；不会改变 VPN 连接。
- 万年历：本机保存生日、日程、显示偏好；用户主动保存时可向所选通讯录联系人写入生日、向系统日历写入日程。不会把这些数据发给节假日服务。
- Codex 重置：仅调用社区站点公共 API，不读取用户 OpenAI 账户。
- Mac 实时监测：读取本机硬件状态与物理网卡字节计数，不上传遥测、不读取 VPN 配置。系统功率为传感器估算，不含外接显示器。Nikki 与 Mac 监测的组件数据桥分别仅监听 127.0.0.1:18765 / 18766，只有只读快照。

请求会访问所配置服务器、公开节假日/API 来源和所选测速站点。源码和安装包不包含服务账户；依赖站点有自己的使用政策。不要在 Issue、截图或日志中提交个人密钥。通用安装包从公开源码独立构建，使用前请先核对 SHA256SUMS。

更新仅请求固定 GitHub 清单和 Release 文件，不附带本机设备映射、联系人、订阅或密钥，关闭系统信息上传。下载连接本身仍会向 GitHub 提供正常 HTTP 请求信息。家庭高级实体别名保存在用户应用支持目录 HomeEnergy/entity-overrides.json，仅本机读取，不随包分发。公开源码和二进制均检查个人路径、私网地址、设备唯一标识和凭据特征；第三方采集器内的上游构建路径按已核对的固定文件摘要单独登记。
