# 另一台 Mac 安装与复现布局

把参考截图与下面文字一同发给新电脑上的 Codex：

> 请从 https://github.com/SOSO-245/mac-desktop-widgets 安装桌面工具箱，以及万年历、Mac 实时监测、Codex 重置、VPN 实时卡片。以仓库 main 的各应用独立 updates 清单和 Release 为准；发行可能是增量版本，不要只看仓库一个 Latest。工具箱至少 1.1.0。下载后核验摘要、应用身份和更新签名，不关闭系统安全校验。
>
> 请参照我附的截图配置为一列：最上方万年历中号日期天气卡片 344×164；第二行 Mac 小鸭子小号 164×164 和 Codex 重置小号 164×164 左右并排；下面是 VPN 大号 344×344。所有间距 16 点，左侧和右侧边缘对齐，从目标显示器左上方可用区域向内 20 点开始。截图像素可能被放大，以 macOS 点数和屏幕可用空间计算，不照抄另一台电脑的绝对坐标。
>
> 万年历选择日期＋天气布局，地点手动选“济南市市中区”，天气使用 Met.no；当前日期和时间动态显示，可点击时间切换12/24小时制。Mac 监测选择动画皮肤和黄鸭，显示本机实际功率估计、温度、CPU、内存和网速。Codex 小号保留经过天数/计划倒计时、最近重置、感谢和来源入口。VPN 大号保留套餐、节点、上下行及六站点延迟，六站为 Google、GitHub、YouTube、ChatGPT、Claude、bilibili。
>
> 所选卡片统一使用现有蓝色毛玻璃效果：明暗约 -14、背景透明度约37%；文字保持清晰。通过工具箱先预览，再确认应用。启用“应用时隐藏未勾选卡片”，不用的 Nikki、API、家庭概览保持未勾选。将启用的卡片锁定位置，并按我意愿开启登录启动。打开软件更新，检查全部，可全选需要维护的软件；更新选择与桌面显示选择独立。
>
> 账户、API Key、VPN/路由器连接、联系人生日和日程由我在这台电脑自行配置；不要从另一台电脑或截图复制私人数据，不自动改系统代理或切换 VPN 节点。没有真实连接时明确显示待配置，不伪造读数。缺少某项功能时先核对应用实际版本，不用旧构建覆盖新版。
>
> 完成后核验实际桌面：卡片两两不重叠，取消勾选并应用后确实隐藏；重开工具箱能保留选择；更新入口可用。告诉我安装版本和需要我手动允许的系统提示。若这台电脑的功率/温度采集器需要管理员授权，由我在系统窗口操作。
